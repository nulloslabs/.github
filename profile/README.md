## Hi there 👋

We are GlungOS Labs, a non-profit, open-source organization.

We develop [GlungOS](https://github.com/glunguslabs/glungos), a hobby OS written from scratch for x86_64.

GlungOS is mainly a project for learning and experimenting with low-level systems programming.
The project is still heavily under development, so things may be incomplete, unstable, or change without warning.

Contributions, bug reports, and suggestions are always welcome.
